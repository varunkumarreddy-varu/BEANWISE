# Dry Bean Variety Image Sources & Botanical Attribution

This directory contains photographic reference assets for the seven dry bean varieties classified in the BEANWISE platform, adhering to botanical taxonomy and the benchmark Turkish Dry Bean Dataset (*Koklu & Ozkan, 2020*).
